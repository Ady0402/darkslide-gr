# Darkslide GR

简体中文 | [English](README.en.md)

在你自己电脑的浏览器里，给 GR III 换上自己的预设图标和预设名。

![Darkslide GR 编辑界面](docs/images/editor.png)

>
> 弄坏了，碎片归你。如果接受不了相机变成一块精致的砖，请不要刷入。

## 不含任何理光固件

本仓库**不包含**任何理光固件，无论是原厂版还是修改版，也不提供下载。你需要自备官方原件，并确认你有权使用它。

工具只接受下面这一个文件，导入时会自动核对：

| 项 | 值 |
|---|---|
| 机型 / 版本 | GR III · 固件 2.10 |
| 文件名 | `fwdc239b.bin` |
| 大小 | 30,391,780 字节 |
| SHA-256 | `d6a3c9c288d784080e7b283222ecdd8752adfeed6faa36dab44f73115354bfd4` |

自己核对：`shasum -a 256 fwdc239b.bin`（Windows：`certutil -hashfile fwdc239b.bin SHA256`）

## 能做什么

把 GR III 菜单里的预设，换上**你自己的图标和名字**。比如把"正片"改成 "Summer"，配一个你自己设计的小图标，相机菜单里就会这样显示。

**目前可以改的预设**

| 预设 | 图标 | 预设名 |
|---|---|---|
| 正片、交叉冲洗、负片 | ✅ | ✅ |
| 标准 | ✅ | — |
| 其余预设 | 后续版本陆续开放 | |

- **图标两种做法**：上传任意图片，用裁切框选取范围；或者输入几个字母，生成和原厂风格一致的文字图标。
- **预设名**：输入时就会提示能不能用，比如太长、有相机显示不了的字。
- **不会改的**：色彩效果、画质参数和其他设置都保持原样，固件版本仍是 2.10。
- **工程**：自动保存草稿，可以保存多个版本、撤销重做，下次打开接着改。

## 怎么保证安全

- 只接受官方 GR III 2.10 原件，其他文件一律拒绝。
- 每次都从原件重新生成，生成后再用另一套独立的代码拆开核对，**全部通过才提供下载**，并附一份构建清单，记录改了什么。
- 工具内置救机说明：教你刷机前准备好救机卡，出问题时刷回官方固件。

## 快速开始

需要 Python 3.9 或更新版本，没有第三方依赖。

```sh
sh start.sh
```

Windows：双击 `start.cmd`（尚未在 Windows 实机测试）。

启动后会打开 `http://127.0.0.1:8787`，端口被占用时自动换下一个，以终端显示为准。所有处理都在你的电脑上完成，不会上传任何文件。数据保存在本机：Mac 为 `~/Library/Application Support/Darkslide`，Windows 为 `%APPDATA%\Darkslide`，Linux 为 `~/.local/share/Darkslide`；可用环境变量 `DARKSLIDE_DATA` 改位置。

运行测试：`python3 -m unittest discover -s tests`
（如需运行真实固件测试，把环境变量 `DARKSLIDE_OFFICIAL_BIN` 设为你的 `fwdc239b.bin` 路径；不设则自动跳过。）
