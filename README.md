# Darkslide GR

简体中文 | [English](README.en.md)

在你自己电脑的浏览器里，给 GR III 换上自己的预设图标、预设名和关机画面，还能给负片打开颗粒。

![Darkslide GR 编辑界面](docs/images/editor.png)

> [!WARNING]
> **刷入修改版固件有风险，请先读完这一段。**
>
> - 刷入后相机可能无法开机、无法正常工作，甚至**永久变砖**；也可能因此失去保修和官方支持。
> - 作者已在**一台** GR III（固件 2.10）上实机刷入测试：开放的 12 个预设的图标和预设名（含加长到上限的预设名）、关机画面、负片颗粒、几样一起改，以及改完再刷回官方 2.10 原件，都未发现问题。样本只有一台，你填的图标、预设名和图片也没有在真机上试过；生成前的检查都在电脑上离线完成，不能代替真机测试。
> - 本项目与理光（RICOH）没有任何关联，也未获得其认可。作者不对任何损失负责。
> - Darkslide 的产出就是一个固件文件：它**不连接相机，也不碰存储卡**。要不要刷、怎么刷，完全由你决定。
>
> 弄坏了，碎片归你。如果接受不了相机变成一块精致的砖，请不要刷入。

本仓库**不包含**任何理光固件，无论是原厂版还是修改版，也不提供下载。你需要自备官方原件，并确认你有权使用它。

## 能做什么

把 GR III 菜单里的预设，换上**你自己的图标和名字**。比如把"正片"改成 "Summer"，配一个你自己设计的小图标，相机菜单里就会这样显示。

**目前可以改的预设**

| 预设 | 图标 | 预设名 |
|---|---|---|
| 鲜艳、单色、HDR 色调 | ✅ | ✅（最多 12 个字符） |
| 怀旧 | ✅ | ✅（最多 8 个字符） |
| 柔和单色、硬调单色、高对比黑白、正片、银流冲洗、交叉冲洗、负片 | ✅ | ✅（原厂长度） |
| 标准 | ✅ | — |
| 自定义 1/2 | — | — |

- **图标两种做法**：上传任意图片，用裁切框选取范围；或者输入几个字母，生成和原厂风格一致的文字图标。
- **预设名**：输入时就会提示能不能用，比如有相机显示不了的字；到长度上限后不能再输入。英文和简体中文菜单显示新预设名，其他语言保持原厂；名字比原厂英文名长时，另有一种不常用的菜单语言也会显示新预设名。
- **不会改的**：除负片颗粒外，色彩效果、画质参数和其他设置都保持原样，固件版本仍是 2.10。界面里的详细设置卡显示每个预设的原厂默认值，只作参考，要在相机菜单里自己调，不写进固件。
- **工程**：自动保存草稿，可以保存多个版本、撤销重做，下次打开接着改。

**负片颗粒**

打开负片「详细设置」里的颗粒项，档位在相机菜单里调。只支持内置负片。颗粒很细，相机屏幕看整张不明显，放大看得清。

**关机画面**

上传一张图片，自动裁成 3:2 并转换成相机能读的格式，关机时显示你的图（合作款样式除外）。只替换固件里原有的关机图位置，不扩容。可以和图标、预设名生成到同一份固件里，一次刷入（这种组合也已实测）。

![关机画面](docs/images/shutdown.png)

## 怎么保证安全

- 只接受官方 GR III 2.10 原件，其他文件一律拒绝。
- 每次都从原件重新生成，生成后再用另一套独立的代码拆开核对，**全部通过才提供下载**，并附一份构建清单，记录改了什么。
- 再加一道与改动内容无关的救机检查：版本仍是 2.10，开机引导记录和作者分析出的刷机更新区域一个字节没动。目的是让刷完之后仍能用官方原包刷回来；刷回官方原件已在一台 GR III 上实测成功；这仍是电脑上的离线检查加一台相机的实测，不是保证，完全开不了机的情况不在覆盖内。
- 工具内置救机说明：教你刷机前准备好救机卡，出问题时刷回官方固件。

## 快速开始

需要 Python 3.9 或更新版本，没有第三方依赖。

```sh
sh start.sh
```

Windows：双击 `start.cmd`（尚未在 Windows 实机测试）。

启动后终端会打印实际地址，浏览器也会自动打开它（通常是 `http://127.0.0.1:8787`；这个端口已被别的程序占着时，会顺延到后面第一个空闲端口）。所有处理都在你的电脑上完成，不会上传任何文件。数据保存在本机：Mac 为 `~/Library/Application Support/Darkslide`，Windows 为 `%APPDATA%\Darkslide`，Linux 为 `~/.local/share/Darkslide`；可用环境变量 `DARKSLIDE_DATA` 改位置。

运行测试：`python3 -m unittest discover -s tests`
（如需运行真实固件测试，把环境变量 `DARKSLIDE_OFFICIAL_BIN` 设为你的 `fwdc239b.bin` 路径；不设则自动跳过。）
